Fix a Windows PC that won't start

You need a second, working Windows 11 PC to make the stick, a USB stick of 8 GB or more, and about twenty minutes.

Copy your files off first. Any repair of a PC that won't start can go wrong. Button 5 on the Fix it page copies your user folders to another drive before you try anything bigger.

1. Make the stick

  1. On the working PC, download the release zip from GitHub releases and unzip it.
  2. Install Microsoft's ADK and WinPE add-on: right-click build\get-adk.cmd and run it as administrator.
  3. Copy the recovery image: run reagentc /info in an administrator terminal, open the folder it names, and copy the hidden Winre.wim to your user folder as Winre-win11.wim.
  4. Plug in the stick and run build\build-media.cmd "%USERPROFILE%\Winre-win11.wim" E: as administrator, with your stick's letter instead of E:. This erases the stick.
  5. Later rebuilds don't need to erase it: build\fix-stick.cmd rebuilds the image and copies it over, checking every file.

2. Boot the broken PC from it

  1. Plug the stick into the broken PC and switch it on. Press the boot menu key (often F8, F11, F12 or Esc) and pick the USB stick.
  2. Violet Rescue opens by itself. It finds the drive with Windows on it and shows it top right.
  3. Pick a page on the left. Scroll with the wheel, by dragging, or with the arrow keys. Anything that changes the PC asks first: Enter is yes, Esc is no.

3. Go down the list

After each step, shut down, take the stick out and try Windows. Stop as soon as it starts.

4. When System Restore fails

Open Restore points. Three ways back, each still working if the one before it fails:

Safer System Restore

Repairs the disk, moves aside the folder restores usually fail on, then runs System Restore.

Registry from a restore point

Copies the registry out of a restore point. It checks the copy loads before using it.

Violet snapshots

Your saved registry copies. List snapshots, pick a row, Put selected back. Every put-back saves the current registry first, so it can be undone.
